# EnterTask

> **Legacy Project** – This is an early learning project from my first year of college, preserved for historical and sentimental reasons.

## Story / Background

This was my first-ever GitHub project, created during my first year of college while I was learning the fundamentals of web development. I built this entirely from scratch using pure HTML, CSS, and JavaScript—no frameworks, no libraries—just to understand how DOM manipulation, event handling, and CSS transforms work.

It's a simple demo, but it represents an important milestone in my learning journey. I've kept it here to remember where I started.

## Features

- **Floating Action Button (FAB)** – A circular button with a hamburger menu icon
- **Interactive Menu Animation** – Click the FAB to reveal 3 hidden menu buttons
- **Staggered Opacity Transitions** – Buttons appear/disappear sequentially with smooth CSS transitions
- **Hover Effects** – Color changes and shadow effects on hover
- **Pure Vanilla JavaScript** – DOM manipulation without any frameworks

## Usage

Simply open `index.html` in a web browser. Click the floating action button to see the menu animation in action.
